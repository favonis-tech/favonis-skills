# 公文写作参考

依据《党政机关公文处理工作条例》（2012）和 GB/T 9704-2012《党政机关公文格式》。企事业单位的公文参照执行，可以不排版头、不编发文字号。

## 1. 选文种

| 文种 | 用途 | 行文方向 |
| --- | --- | --- |
| 决议 | 会议讨论通过的重大决策事项 | 下行 |
| 决定 | 对重要事项作出决策和部署、奖惩有关单位和人员、变更或撤销下级机关不适当的决定 | 下行 |
| 命令（令） | 公布行政法规和规章、宣布施行重大强制性措施、批准授予和晋升衔级、嘉奖 | 下行 |
| 公报 | 公布重要决定或者重大事项 | 下行、周知 |
| 公告 | 向国内外宣布重要事项或者法定事项 | 周知 |
| 通告 | 在一定范围内公布应当遵守或者周知的事项 | 周知 |
| 意见 | 对重要问题提出见解和处理办法 | 上行、平行、下行 |
| 通知 | 发布、传达要求下级执行和有关单位周知或执行的事项，批转、转发公文 | 下行、平行 |
| 通报 | 表彰先进、批评错误、传达重要精神和告知重要情况 | 下行 |
| 报告 | 向上级汇报工作、反映情况，回复上级的询问 | 上行 |
| 请示 | 向上级请求指示、批准 | 上行 |
| 批复 | 答复下级的请示事项 | 下行 |
| 议案 | 各级人民政府按法律程序向同级人大或其常委会提请审议事项 | 上行 |
| 函 | 不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项 | 平行 |
| 纪要 | 记录会议主要情况和议定事项 | 下行、周知 |

容易混用的几组：

- **请示和报告**：要上级批准或答复的用请示；只汇报情况、不需要答复的用报告。报告里不得夹带请示事项。
- **请示和函**：向有隶属关系的上级请求批准用请示；向不相隶属的主管部门请求批准（例如向财政局申请资金、向自然资源局申请用地审批）用函。
- **通知和通报**：要对方执行或知晓具体事项用通知；表彰、批评、告知情况用通报。
- **批复**只回复请示，一事一复；回复函用复函。
- 企业内部常用通知、请示、报告、函、纪要、通报、决定；规章制度用「办法」「规定」等，作为通知的附件印发。

## 2. 行文规则

- 按隶属关系行文，一般不越级；确需越级时同时抄送被越过的机关。
- 向上级行文：原则上主送一个上级机关，不抄送下级机关；上行文标注签发人。
- **请示一文一事**，只主送一个上级机关；下级的请示事项需以本机关名义上报时，先提出倾向性意见，不得原文转报。
- 不得以本机关名义向上级机关负责人个人报送公文（负责人直接交办的除外）。
- 向下级行文：主送受理机关，重要行文同时抄送发文机关的直接上级。
- 同级机关可以联合行文；属于各自职权范围内的工作不联合行文。联合行文使用主办机关的发文字号，成文日期署最后签发机关负责人签发的日期。

## 3. 标题

- 由发文机关名称、事由和文种组成：「××市人民政府关于做好××工作的通知」。有版头时可以省略发文机关名称。
- 标题一般不用标点，可以用书名号、引号、顿号、连接号和括号。
- 转发、批转时避免「关于」「的通知」重叠：「××关于转发《××关于××的通知》的通知」可简为「××关于转发××工作方案的通知」。
- 多行标题按词意回行，不拆开词语和机关名称，排成梯形或菱形（上短下长或中间长），每行不超过 20 字。

## 4. 各文种的结构

正文一般是「缘由（依据、目的）→ 事项 → 结尾」。层次序数依次用「一、」「（一）」「1.」「（1）」：「一、」后用顿号，「（一）」「（1）」后不再加标点，「1.」用半角下脚点。层次少时可以从「一、」直接用「1.」，但同一层级要用同一种序数。

**通知**

- 开头：为了……，根据……，现就……通知如下（现将……通知如下）。
- 事项：分条写清做什么、谁来做、何时完成、标准是什么。
- 结尾：有具体要求的以要求收尾；无需另写要求的用「特此通知」。
- 印发、转发类：「现将《……》印发给你们，请认真贯彻执行。」规章、方案作为附件。

**请示**

- 开头：请示的缘由和依据，写清必要性和现状。
- 事项：请求批准或指示的具体事项，一文一事；涉及资金、编制的写明数额和测算依据；提出本机关的倾向性意见。
- 结尾：「妥否，请批示」「以上请示，请予审批」「当否，请批复」。

**报告**

- 工作报告：基本情况 → 主要做法和成效 → 存在问题 → 下一步打算。
- 情况报告：事情经过 → 原因 → 处理情况 → 意见建议。
- 答复报告：针对上级询问逐项回答。
- 结尾：「特此报告」「专此报告」。不写「请批示」。

**函**

- 商洽、询问：说明缘由，提出具体事项，「请予函复」「盼复」。
- 请求批准：说明缘由和依据、请求事项，「请予研究批准」。
- 复函：「你单位《关于××的函》（×函〔2026〕×号）收悉。经研究，函复如下：……」「特此函复」。
- 语气平和、得体，不用指令性语言。

**批复**

- 「你单位《关于××的请示》（×〔2026〕×号）收悉。经研究，批复如下：……」
- 明确同意、部分同意或不同意，不同意的说明理由；提出执行要求。
- 结尾：「此复」「特此批复」。

**纪要**

- 开头：会议时间、地点、主持人、议题，「现将会议议定事项纪要如下」。
- 主体：按议题写，用「会议认为」「会议指出」「会议强调」「会议同意」「会议要求」「会议决定」引出；写议定事项和分工、时限，不写发言实录。
- 出席、请假、列席人员写在正文之后。

**通报**

- 表彰：事迹 → 评价 → 表彰决定 → 号召。
- 批评：事实 → 性质和原因 → 处理决定 → 要求。
- 情况通报：情况 → 分析 → 要求。

**意见**

- 指导性意见（下行）：总体要求 → 主要任务 → 保障措施，可以要求「认真贯彻落实」。
- 建议性意见（上行）：结尾「以上意见如无不妥，请批转各地执行」。

## 5. 语言与规范

- **准确、简明、庄重。** 用书面语，不用口语、网络语、夸张修辞。四字格、「进行」「按照」「切实」等正式表达是公文的正常语体；要删的是没有信息量的空话和重复的套话，例如没有具体举措的「高度重视、认真落实、狠抓落实」连用。
- **事实具体。** 写明具体日期，不写「近日」「今年」这类相对时间；任务写明责任单位和完成时限；不确定的数字、名称、文号留「××」占位，不编造。
- **机关名称**用全称或规范化简称；简称首次出现时写全称并注明「（以下简称××）」。
- **引用公文**先引标题，后引发文字号：《××市人民政府关于××的通知》（×政发〔2026〕12号）。
- **数字**按 GB/T 15835：计量、统计、编号和公历日期用阿拉伯数字；数字作为词素构成的定型词语用汉字（如「一律」「三令五申」「十四五」）；相邻两个数字表示概数用汉字，不加顿号（如「三四个」）。成文日期写「2026年10月14日」，月、日不编虚位。
- **标点**按 GB/T 15834。主送机关后用全角冒号；附件名称后不加标点；抄送机关最后用句号。
- **附件**：附件说明的名称和顺序要与附件页的标题一致；附件说明写在正文之后、署名之前。

## 6. 交付前核对

- 文种与用途、行文方向相符；请示一文一事、只主送一个上级机关。
- 标题有事由和文种，回行合理；主送机关正确且用全称或规范化简称。
- 层次序数连续、同级一致；结尾用语与文种相符。
- 发文字号、成文日期、附件说明、抄送和印发信息齐全且格式正确。
- 没有编造的事实、数字、人名和文号；占位符已列给用户。
- 版式检查见 SKILL.md 的工作流程第 5、6 步。
